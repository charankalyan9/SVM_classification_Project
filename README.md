# Iris Dataset SVM Regression using Streamlit

This project demonstrates Support Vector Machine Regression (SVR)
using the Iris dataset with a Streamlit web application.

## Features
- Uses Iris dataset from scikit-learn
- Performs SVM Regression
- Interactive Streamlit UI
- Displays evaluation metrics

## Project Structure

```
iris_svm_streamlit_project/
│── app.py
│── requirements.txt
│── README.md
```

## Installation

Clone the repository:

```bash
git clone <your-github-repo-link>
cd iris_svm_streamlit_project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Streamlit App

```bash
streamlit run app.py
```
